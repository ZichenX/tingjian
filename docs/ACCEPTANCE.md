# 目标服务器与真实手机验收单

这里是待目标环境执行的清单，不是本仓库已经全部通过的声明。记录日期、服务器配置、模型lock与实际结果。

## A. 安装与真实推理

- [ ] 入口方案已记录：Caddy路径需域名A/AAAA与80/443可达；Tunnel路径需固定hostname、Named Tunnel route与同节点 connector；两条路径都不公开8000。
- [ ] 所选模型条款已审阅；默认免访问码，或兼容模式使用的访问码不是示例值；.env权限600，未进仓库。
- [ ] 下载完整性校验通过；保留artifacts.lock.json及必要的独立可信hash。
- [ ] 所选模式 self_test 真正输出非空ASR；dual还需CTC预览样例；VAD有片段。
- [ ] 开启TTS时真实生成WAV，人工播放确认确实是普通话，不只是一个有效WAV头。
- [ ] 检查实际峰值内存/RTF；没有OOMKilled或反复超时重启。
- [ ] 公网可信HTTPS /health/ready成功，不使用-k、不接受证书警告；Tunnel路径确认 Cloudflare route 与 app 的固定 `APP_ORIGIN` 一致。

## B. 手机移动网络（不是只在服务器或同Wi-Fi测试）

- [ ] 首次访问无需登录码即可进入；若启用了 `AUTH_REQUIRED=1` 兼容模式，再验证错误/正确访问码提示。
- [ ] 刷新后会话保留；字体“大/更大/特大”可切换，竖屏无横向溢出，可正常缩放。
- [ ] 拒绝麦克风权限时提示可理解；允许后成功收音；拔掉耳机/占用麦克风有失败提示。
- [ ] 讲一段实际山东方言，有适当预览/停顿定稿；预览与定稿标识不同。
- [ ] 故意在句尾没有长静音时立即停止，最后的字不会因为不足一帧而静默丢掉。
- [ ] 连续说超过12秒、有长停顿/语气词；不会无限等待、无限增长或重复整句。
- [ ] 关闭网络或切后台，已确认文字还在；不会自动恢复偷录或把未确认预览保存成最终稿。
- [ ] 同一个公网IP/总容量达到限制时第二路有“服务器忙”等提示，而不是拖垮主机。

## C. 录音与朗读

- [ ] 真实WAV、手机M4A、至少另一常见格式上传成功；超过限制明确拒绝，不悄悄截断。
- [ ] 上传进度/部分结果可见；取消保留已有文字；损坏音频有清楚错误提示。
- [ ] 普通话朗读需要先停麦克风；允许修改文本/直接打字；慢/正常/快可用。
- [ ] 多句朗读顺序正确；停止按钮能停止播放；浏览器拦截播放时原生控件可手动播放。
- [ ] 字词、姓名、数字实际发音可以接受；方言语义没有被宣称自动翻译。
- [ ] 保存TXT仅含最终文字，无未确认预览；中文编码正常；清空有二次确认。
- [ ] 使用实际iPhone/Android中的目标浏览器，不只依据桌面模拟器。

## D. 试运行、安全与质量

- [ ] 用经授权、人工标注的山东真实录音做CER/实体错误评测，按目标地区/长者/噪声分组。
- [ ] 对所选引擎在正常CPU负载、弱网和预计并发下测停顿至定稿延迟，不只看离线RTF。
- [ ] 执行镜像/依赖漏洞审查；凭据、日志、私钥卷、评测录音未对外暴露。
- [ ] 若启用了兼容访问码模式，轮换后旧Cookie无效；默认免登录模式验证会话过期和重新签发。
- [ ] 容器/服务器重启后可恢复；Caddy证书数据卷或 Tunnel connector 的作业/服务保活策略持久；备份与回滚演练完成。
- [ ] 有明确管理员与故障联系方式；用户理解重要信息需人工复核，项目不是紧急通信保障。
