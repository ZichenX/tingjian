# 安全与隐私说明

此项目是小规模服务。默认不要求访问码，但仍使用签名浏览器会话和请求校验；已有加固措施，但没有完成独立安全审计，“能公网访问”不等于“能承受无限匿名访问”。

## 已实现的边界

默认路径是仅 Caddy 暴露80/443、应用8000只在内部网络；另一条受支持路径是 Cloudflare Named Tunnel 直接连接 loopback app，TLS 在 Cloudflare 边缘终止，不开放入站端口。Caddy路径覆盖X-Real-IP；Tunnel路径只在 loopback 对端时使用 Cloudflare 的 CF-Connecting-IP，应用不信任任意外来代理头。Uvicorn不自动信任代理头。Cookie由随机签名密钥保护，Secure/HttpOnly/SameSiteStrict（localhost开发模式不Secure）。访问码PBKDF2-SHA256、310000轮与随机salt，不存明文。签名Cookie最长30天默认；CSRF绑定会话。POST和WS精确校验Origin。Host白名单，不开放跨域。

有兼容登录（启用时）、WS、音频帧、上传与TTS频率限制；默认两路live、每公网IP一路、同会话不能同时跑live/upload/tts、全局最多一个上传和一个TTS请求。ASR/TTS队列最多12项；预览不积压；单连接最多4个未完成定稿。文件体积、解码时长、控制消息长度、PCM帧长度、采样率、TTS字符和语速均受限制。

模型调用串行化；不可取消的native执行不会被假装取消后开新线程。模型超时主动退出进程，让Docker恢复。应用非root、只读文件系统、移除capabilities、no-new-privileges、进程/内存上限；上传临时目录在tmpfs。FFmpeg不经shell，不接URL，限制协议/解复用器/线程/超时。

CSP、自源静态资源、无第三方CDN/分析脚本、禁iframe嵌入；转写内容使用textContent而非HTML。无永久转写库、录音库或公网文件目录；日志不主动记录请求体、音频、Cookie和完整用户文本。下载器只使用HTTPS，安全解压并建立SHA256内容锁。

## 没有解决的事项

**没有DDoS防护能力承诺**；边缘带宽攻击发生在应用鉴权之前。没有独立实名/逐用户账户、持久配额、计费、租户隔离、管理员后台、跨实例限流或完整审计。内存计数随应用重启清空；大量不同IP可能共享运营商出口，当前每IP一路限制会误限正常用户。

共享访问码不是可撤销的逐用户权限系统。普通退出只删除当前浏览器Cookie；被盗Cookie在到期/全局密钥轮换前仍有效。访问码泄露时使用configure.py --rotate-code并重新部署，签名密钥会一起轮换。不要把源码包默认测试访问码或测试签名密钥用于生产。

不提供端到端加密：Caddy路径中 TLS 终止于你的 Caddy；Cloudflare Tunnel 路径中浏览器 TLS 终止于 Cloudflare 边缘，随后通过 Tunnel 到达服务器。服务器需要读取音频进行识别，Cloudflare 作为传输代理也会处理请求内容和连接元数据。若不接受第三方传输代理，不能使用 Cloudflare 路径。运营者和拥有主机root/Docker权限的人仍可接触内存或请求。需要严格保密等级时，必须另行设计账号、访问控制、隔离、存储及合规体系。

“不长期保存”不等于操作系统级零残留。临时文件的清理不保证没有swap、core dump、备份、管理员自加代理日志、浏览器内存或用户自行下载的文本。要求更严时，应禁用不必要的core dump、加密系统存储、控制swap与备份，并审查基础设施日志。

模型来自固定官方URL，但首次SHA256默认是TOFU，不是签名证明；严格部署需要管理员预置独立核实的checksum。直接依赖固定、镜像记录传递依赖，不等于经过漏洞扫描或永远安全。上线前与持续维护时应扫描镜像、审查依赖与重新验收安全更新。

## 对外使用前

默认关闭访问码是本项目的直接进入模式；若面向不特定公众，应在 Cloudflare Access/WAF 或应用兼容模式增加访问策略。不要把8000端口直接开放来解决“朋友连不上”，也不要暴露Docker socket、私钥卷、.env或模型评测中的私人录音。不添加 `--privileged`、不跳过TLS校验，不为了速度移除长度和队列限制。采用CDN/多级反代时必须重新核实真实IP、WebSocket、body限制与隐私告知。

共享设备缩短Cookie有效期；告诉用户先保存需要的文字、结束后退出。取得适当的录音/处理授权。姓名、金额、用药等重要文本以人工确认信息为准，不把自动字幕作为唯一决策依据。本产品是沟通辅助工具，不是经过认证的医疗或紧急通信系统。
